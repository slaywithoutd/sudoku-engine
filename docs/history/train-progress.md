## T1 pack (2026-11-13)

Power: mains (`BatteryStatus` 2), CPU 1.6 GHz (slow state).

- First harvest probe with the full technique set and a 40M-unit budget ran at well over 2 s per seed: hard generated puzzles spent the budget in tier >= 3 searches. The builder now runs Explain with the M2.7 `up-to-wings-fish@1` set (tiers 0-2) and a 4M-unit budget; a tier <= 2 step is never set-limited under that set, so the "no simpler step" label is unchanged. About 0.7 s per seed.
- Probe over the first 125 seeds: about 29 technique positions per 100 seeds (C04, C11, C10 common, C06 rare, no C05 or C13).
- Full build (`TRAIN_PACK=write`, 861 s): 500 positions from 863 seeds and 373 source puzzles (at most 3 each). Scan 200 (cap); C04 subsets 116, C11 wings 107, C10 single-digit patterns 65, C06 fish 12. Tiers 0/1/2: 200/116/184. 331,142 bytes, sha256 `f51d3cf3…20b4`.
- `npx vitest run tests/unit/training-pack.test.ts`: 502 passed (3.2 s).
- Independent review: no acceptance bug; one medium finding: 184 of 300 technique positions (every C06, C10 and C11 entry) had no pattern cells, because the engine's presentation-only `patternCells` read only `cell`/`cells` keys. Fixed in `src/solver/classic-run.ts`: it also reads the wing (`pivot`, `wings`, `endpoints`, `bridge`), short-path (`vertices`) and fish fields (`fins`, and the base houses' cells that hold the fish digit in the candidates before the step); chain vertices are still walked as objects. Presentation only: the Solve screen now also highlights these patterns' cells. Pinned by `tests/unit/solver/pattern-cells.test.ts`. Also from the review: the builder asserts that a step's `values` are the board before plus its placements; the checker holds its own tier table, requires pattern cells on technique positions and follows imports transitively; a puzzle no longer keeps a slot for a scan position once scans are at their cap.

## T3 run screen (2026-11-13)

- Route `#/train/run`, sidebar entry and a fourth Home card ("Train"; Home cards now four across). The run screen reuses the puzzle surface (board, keypad, keyboard) with every placed digit as a given; a technique position shows the pack's candidates as read-only notes; the keypad's tools and edit actions are hidden. Any digit equal to the solution in any empty cell is correct; a wrong digit ends the attempt, draws the intended placements and resets the streak. The clock is the Play clock; pausing, hiding the page or leaving the window covers the board and stops it. Nothing is written before the answer.
- `npx playwright test tests/e2e/train.spec.ts`: 4 passed (correct → streak 1 and a stored time ≥ 3.5 s of a 4 s fake clock; wrong → streak 0, a miss queued at due 12, every target drawn; blur → cover, a minute away not counted; reload → no attempt stored). Router unit tests: 10 passed.
- Independent review: Shift or Ctrl with a digit (the note modifiers) submitted an answer; a test step passed without checking anything; a screen mounted without focus left the board uncovered while the clock was stopped. Fixed, with tests: only a plain digit answers; the blur test now presses a digit on a selected cell while covered and runs the clock after focus returns; an unfocused mount or advance pauses. Also: focus returns to the board after Next, the result is announced through an always-present live region, and "No category selected" replaces "Sprint complete" when every category is off. Noted, not changed: a reload starts a new sprint, so positions seen before it can come back. Home with four cards checked at 1150 px. `train.spec.ts`: 5 passed.

## T5 explanation after the answer (2026-11-13)

- After every answer (correct or missed), the result panel says "Found with" the technique (the category name for a technique position, since the engine names the whole C04 family "Naked Pair"; the single's name for a scan position), the removals and the placements they leave, with the Solve screen's legend. The board draws the key step as Solve does: pattern cells as reasoning, removed candidates struck through, resulting placements; the player's peer and same-digit highlights are off while it shows. The study view shows the same step on "Show the answer". Never "requires".
- `npx playwright test tests/e2e/train-explain.spec.ts`: 3 passed. A miss and the study view show the same step text. All Train specs: 10 passed.
- Independent review, one acceptance gap: targets were drawn as placements, and a cell showing a digit shows no notes, so on 144 of the 300 technique positions some removed candidates were never drawn (92 lost all of them); the test position happened to avoid it. New tests answer in such a cell on the run screen (both modes) and open four such positions in the study view; a shared `expectStep` checks pattern cells, every struck candidate and the remaining placements. All Train specs: 11 passed.

## T6 timed run (2026-11-13)

Done because T1–T5 had passed their acceptance and reviews; the whole-suite gate covers T1–T6 together.

- `#/train/timed` (hub button "Timed run"): positions follow one another without the step in between; a status line shows solved and misses; the clock shows the time left. The run ends after 180 s of active time (pauses and hidden time do not count), at the third miss, or when the selected categories run out. It is recorded once in `training.runs` (count, best, ring of 20 runs: solved, misses, active ms); a run left before its end is not recorded, while its answered attempts are ordinary attempts. The hub shows the best run. Format version stays 4 (not released yet).
- Found by the tests: after the third miss the sprint result panel also showed (the last answer was not cleared); after an auto-advance the previous cell stayed selected through the keyboard-focus handoff, which would make a click on that cell deselect it. Both fixed.
- `npx playwright test tests/e2e/train-timed.spec.ts`: 3 passed (third miss ends and records once, nothing more after it; three active minutes end the run with ms 180000 and a five-minute pause does not count; a second run left early is not recorded; nothing selected after an answer). All Train specs: 14 passed. `training.test.ts`: 46 passed.
